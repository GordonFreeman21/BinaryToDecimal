## Binary-to-Decimal Converter ##


A simple yet efficient converter that transforms binary numbers into their decimal equivalents. Available in multiple programming languages for maximum flexibility.
Features

* Converts binary strings to decimal numbers
* Input validation to ensure only 0s and 1s are accepted
* Error handling for invalid inputs
* Multiple language implementations

## How to Run

use this: 
``powershell
node binaryConverter.js
``
Put any valid binary string in like 101 and it will come 5
